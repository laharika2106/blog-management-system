# 📝 Blog Management System

A simple and responsive **Blog Management System** built using **HTML, CSS, JavaScript, Node.js, and Express.js**. This project demonstrates full CRUD (Create, Read, Update, Delete) operations using REST APIs.

---

## 🚀 Features

- ✍️ Add a new blog
- 📖 View all blogs
- ✏️ Edit existing blogs
- 🗑️ Delete blogs
- 🔍 Search blogs by title or author
- ✅ Form validation
- 📱 Responsive user interface
- ⚡ REST API integration using Fetch API

---

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/blog-management-system.git
```

### 2. Navigate to the project folder

```bash
cd blog-management-system
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node server.js
```

---

## 🌐 Open in Browser

```
http://localhost:3000
```

## 📌 API Endpoints

| Method | Endpoint | Description |
|---------|----------|-------------|
| GET | `/blogs` | Get all blogs |
| POST | `/blogs` | Add a new blog |
| PUT | `/blogs/:id` | Update a blog |
| DELETE | `/blogs/:id` | Delete a blog |
